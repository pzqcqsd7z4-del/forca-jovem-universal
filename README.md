# Força Jovem Universal

Website da Força Jovem Universal.

## Ficheiros
- `index.html`: site completo, com recursos incorporados.

## Abrir o site
Descarrega `index.html` e abre-o num navegador com JavaScript ativado.

## Histórico de alterações
O GitHub guarda o histórico das versões enviadas ao repositório.

## Publicação
É possível configurar GitHub Pages nas definições do repositório, caso pretendas disponibilizar o website publicamente.
